# 🌱 Smart Fertilizer Recommendation System

This project uses Machine Learning and Streamlit to recommend suitable crops and fertilizer adjustments based on soil parameters.

## 🚀 Features
- Crop prediction using AI
- Fertilizer suggestions
- Interactive web interface
- Data visualization

## 📊 Input Parameters
- Nitrogen (N)
- Phosphorus (P)
- Potassium (K)
- Temperature
- Humidity
- pH
- Rainfall

## 🧠 Technology Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Matplotlib

## ▶️ How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
